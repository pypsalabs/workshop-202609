# Welcome

<img src="https://docs.pypsa.org/latest/assets/logo/logo-primary-light.svg#only-light" width="300px" />

Welcome to the PyPSA workshop in Birmingham (September 2026)! This workshop introduces you to PyPSA ecosystem and the basics of using PyPSA for energy system
modelling.

PyPSA is an open-source Python framework and stands for **Python for Power
System Analysis**.

PyPSA is made for optimising and simulating modern power and energy systems that
include features such as conventional generators with operational constraints,
variable wind and solar generation, hydro-electricity, storage, coupling to
other energy sectors, and linearised power flow with loss approximations.

Applications range from short-term operational problems under security of
supply considerations to long-term capacity expansion and investment planning
under uncertainty.

For working with PyPSA, we depend on some Python and `pandas` basics.
Python is a programming language that is widely used in scientific computing and
data analysis. `pandas` is the core library for handling tabular data in Python.
Think of it as Excel but with code. You will find introductions to both in the
annex chapters of this website.

:::{note}
Checkout the [PyPSA documentation](https://docs.pypsa.org) for more details.
:::
